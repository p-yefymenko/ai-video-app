# 4. Clips

For every clip in `epNN/clips.md` that has no `epNN/<clip>.mp4`, generate a video and save it there.

- **References:** `refs/<id>.png` for each id in the clip's `Refs`. Use them as references, not as a start frame.
- **Prompt:** the clip's text and the show's Style. Wherever a character speaks, add that character's Voice from `show.md`, word for word. End with: "Nobody looks into the camera."
- **Format:** vertical 9:16, 720p, the clip's Length, with audio.

Watch every clip from start to end. Make it again if anyone looks at or talks to the camera, or if anything is physically wrong: a body merging into the floor or furniture, a person vanishing or appearing out of nowhere.
