# 3. Reference images

For every character, place and thing in `show.md` that has no `refs/<id>.png`, generate one image and save it there.

- **Character:** the character's Look plus the show's Style. Waist-up, facing the camera, neutral expression, plain light grey background, soft even light, no text.
- **Place:** the place's description plus the show's Style. Wide shot, no people, nothing that isn't in the description, no text.
- **Thing:** its description plus the show's Style. The whole thing in view, plain light grey background, no people, no text.

Generate each image once; never remake one on your own. If one clearly doesn't match its description, say so in your final reply.

If the image tool can't save an image to disk, make a 1-second video with it as the start frame, then save that video's first frame as `refs/<id>.png`.
