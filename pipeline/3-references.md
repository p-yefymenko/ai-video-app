# 3. Reference images

For every character and place in `show.md` that has no `refs/<id>.png`, generate one image and save it there.

- **Character:** the character's Look plus the show's Style. Waist-up, facing the camera, neutral expression, plain light grey background, soft even light, no text.
- **Place:** the place's description plus the show's Style. Wide shot, no people, no text.

Look at each image. If it doesn't match the description, make it again.

The image tool can't save files to disk. To save an image, make a 1-second video with it as the start frame, then save that video's first frame as `refs/<id>.png`.
