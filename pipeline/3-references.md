# 3. Reference images

For every character and place in `show.md` that has no `refs/<id>.png`, generate one image and save it there.

- **Character:** the character's Look plus the show's Style. Waist-up, facing the camera, neutral expression, plain light grey background, soft even light, vertical 9:16, no text.
- **Place:** the place's description plus the show's Style. Wide shot, no people, vertical 9:16, no text.

Look at each image. If it doesn't match the description, make it again.
