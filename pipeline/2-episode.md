# 2. Episode

Skip if `epNN/shots.md` exists.

Read `show.md` and every earlier `epNN/shots.md`. If the Episodes list has no line for the current episode, add one that continues the story in the same style.

Write the current episode as `epNN/shots.md`: about one minute, 5–8 shots, following its line in the Episodes list and ending on a hook.

If the episode needs a new character or place, add it to `show.md` first, in the same format.

Format:

```
# Episode 1: <title>

## 01
Characters: seo-yeon, jae-min
Place: cafe
Length: 8
Action: what happens and what the camera sees, in one or two sentences.
Dialogue:
- Jae-min: "You're always open this late."
- Seo-yeon: "I don't sleep much."
```

`Length` is in seconds, 4–15. A shot can have no dialogue.
